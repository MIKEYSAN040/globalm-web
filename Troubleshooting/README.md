
# AWS Troubleshooting & Incident Response

This directory demonstrates practical **Cloud Support troubleshooting** through intentionally reproduced AWS incidents.

Each incident follows a real-world support workflow:

**Detect -> Investigate -> Identify Root Cause -> Remediate -> Validate -> Document**

### Purpose

These incidents demonstrate the ability to approach cloud issues from a Cloud Support Engineer perspective—not just configuring AWS services, but systematically diagnosing failures, identifying root causes, restoring service, and documenting the resolution.
